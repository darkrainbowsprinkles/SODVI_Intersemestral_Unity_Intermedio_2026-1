# Curso Intersemestral 2026-1 - SODVI Unity Intermedio

## Contenido:
Desarrolla un horror-survival FPS mientras aprendes conceptos intermedios y avanzados de Unity 6 y C#.

## Temario:
- Cinemachine.
- Raycasting.
- NavMesh.
- Scriptable Objects.
- Terrain Tools.
- Observer Pattern.
- MVP Architecture.
- New Input System.
- Abstract Classes.
- Animation Blend Trees.
